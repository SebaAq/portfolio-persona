# Portfolio

Plantilla de portfolio personal con estética de menú de videojuego: pantallas que cambian con una transición diagonal, navegación con teclado (↑ ↓, Enter, Esc), escenas animadas en canvas y efectos de sonido sintetizados con WebAudio.

Es un solo archivo HTML sin dependencias ni build: abrí `index.html` en el navegador (mejor con un servidor local: `python3 -m http.server`).

Todo el contenido que ves es **de ejemplo**. Para hacerlo tuyo, editá en `index.html`:

- el bloque `/* ====== EDITÁ TUS DATOS ACÁ ====== */` del script: `EMAIL`, `WORK`, `EXP`, `SIDE` y `SKILLS`;
- los textos del inicio, de "Sobre mí" y los links de contacto en el HTML;
- la foto de "Sobre mí" (hoy es un dibujo genérico) y `sumergido.webp`, la ilustración del inicio.

## Publicarlo con GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
